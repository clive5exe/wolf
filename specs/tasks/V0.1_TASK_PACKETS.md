# v0.1 Task Packets

Packets for **open** work (T-022 … T-030). Tasks T-001…T-021 were implemented
in the founding scaffold session; their acceptance criteria live in the specs
they implement and their evidence is the test suite (`scripts/verify.sh`).
Every future task gets a packet in this format before a builder touches code.

---

## Packet template (copy for new tasks)

```
ID · Objective · Business reason · Architecture refs · Inputs → Outputs ·
Allowed paths · Forbidden paths · Acceptance criteria · Non-goals ·
Tests required · Safety class (S0/S1/S2) · Rollback · Completion evidence
```

---

## T-022 — Policy onboarding flow (NL → draft → confirm → active)

- **Objective:** TUI onboarding screen + `PolicyService.draft_from_text()`
  using the provider to fill `PolicyDraft`, then a field-by-field confirm
  form that activates policy v1.
- **Business reason:** PRODUCT.md J2 — the "financial advisor, not chatbot"
  first impression.
- **Architecture refs:** INVESTMENT_POLICY_SPEC §2–3; PROVIDER_SPEC §5; ADR-0011.
- **Inputs → Outputs:** goals text → `PolicyDraft` (provider) → confirmed
  `InvestmentPolicy` v1 + `policy.created` event + notification.
- **Allowed paths:** `src/tradeos/tui/screens/onboarding.py`,
  `src/tradeos/runtime/policy_service.py` (extend), `src/tradeos/providers/prompts.py`
  (add draft prompt), `tests/unit/test_policy_onboarding.py`, `tests/integration/`.
- **Forbidden paths:** `risk/`, `execution/`, `brokers/`, provider adapter internals.
- **Acceptance criteria:** ⚡ fields require explicit confirmation; provenance
  (`user_stated/model_inferred/default`) rendered per field; provider-down
  path falls back to blank form; draft with `autopilot` set is rejected with
  visible message; round-trip test from PRODUCT.md J2 example passes.
- **Non-goals:** editing flows post-activation (separate task), multi-policy.
- **Tests:** unit (draft validation, provenance mapping), Pilot TUI test
  (confirm flow), integration (event emitted, reload identical).
- **Safety class:** S1. **Rollback:** revert commit; no schema/migration changes allowed.
- **Evidence:** verify.sh green + Pilot screenshot in PR + event-log excerpt.

## T-023 — SEC EDGAR connector

- **Objective:** `ingestion/edgar.py`: submissions + companyfacts for tracked
  tickers (CIK mapping), client-side rate limiter (≤5 req/s), declared
  User-Agent from config, raw `ingest.raw` events, normalized `ContextItem`s
  (filing events with true accepted timestamps), "latest-known filing" check.
- **Business reason:** primary durable-knowledge source; v0.1 requirement.
- **Architecture refs:** DATA_SOURCES §1/§4; MARKET_CONTEXT_SPEC §3–4/§8; RESEARCH_NOTES §4.
- **Inputs → Outputs:** ticker list → ContextItems (source_type=FILING,
  credibility 0.95, ttl per spec) in context store.
- **Allowed paths:** `src/tradeos/ingestion/edgar.py`, `src/tradeos/ingestion/ratelimit.py`,
  `tests/unit/test_edgar*.py`, `tests/fixtures/edgar/`.
- **Forbidden paths:** everything else; NO live-network calls in tests (fixtures only).
- **Acceptance criteria:** UA header always present; limiter property test;
  ticker→CIK resolution with padding; malformed JSON quarantined with
  `ingest.error`; event_time = filing acceptance datetime, never ingestion.
- **Non-goals:** full-text search (efts), XBRL frames, bulk zips, transcripts.
- **Tests:** unit with recorded fixtures; contract test for connector interface.
- **Safety class:** S1. **Rollback:** connector is flag-gated (`sources.edgar.enabled`).
- **Evidence:** verify.sh green + fixture-driven run log excerpt.

## T-024 — Robinhood Agentic MCP read-only adapter ▷ BLOCKED (human: Q2)

- **Objective:** MCP HTTP client for `https://agent.robinhood.com/mcp/trading`;
  tool-list probe; allowlist registry enforcement; map account/positions/
  quotes/orders payloads → domain models; `submit_order` raises
  `BrokerCapabilityError` unconditionally.
- **Business reason:** real read-only portfolio path; PRODUCT.md J3.
- **Architecture refs:** MCP_TOOL_SPEC (all); ADR-0004; THREAT_MODEL T7; RESEARCH_NOTES §2.
- **Allowed paths:** `src/tradeos/mcp/`, `src/tradeos/brokers/robinhood.py`,

- **Forbidden paths:** `risk/`, `execution/` internals; no trade-class tools
  in any config, code path, or test fixture.

- **Non-goals:** any write path; options; watchlist writes.
- **Tests:** contract tests against a local fake MCP server fixture
  (timeouts, drift, allowlist); NO live credentials in CI.
- **Safety class:** **S2 — human review + safety suite mandatory.**
- **Rollback:** adapter behind `brokers.robinhood.enabled=false` default.
- **Evidence:** verify.sh + safety_check.sh green; manual connect log
  (redacted) from the human's machine; threat-model delta paragraph in PR.
