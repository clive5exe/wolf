design direction · terminal ui · working title
W◉LF
Wealth Orchestration, Local-First

Six screens, one motion language, one brand mark. The current TUI shows data; this direction makes the runtime feel like what it is — a patient predator that watches everything, explains everything, and only moves when the numbers say move. Every mockup below uses the real numbers from yesterday's paper session.

Animations are live in the mockups — press ▶ replay on any window.

00

THE NAME

recommended

WOLF

Wealth Orchestration, Local-First

The acronym is honest — local-first is the actual architecture, not marketing. Gives us a brand mark for free (the amber eye in the O), a binary that feels good to type (wolf tui), and a voice: "wolf is watching", "enter the den". Risk: the word is common — check crates/pypi/homebrew collisions before committing.

ARGUS

no acronym needed — the hundred-eyed watchman

Mythologically perfect for a monitor-everything runtime; Argus never sleeps. Slightly cold, and heavily used in dev-tools naming (monitoring dashboards especially).

KESTREL

the falcon that hovers, watches, then strikes precisely

Beautiful word, right behavior (hold position → commit decisively). Weak acronym potential; brand mark less obvious than the wolf eye.

HELM

Holdings · Events · Ledger · Markets

You steer, it holds course — matches the "advisor, not chatbot" stance. Calmer, more serious. Kubernetes' package manager owns a lot of this word's tech mindshare.

DRIFT

the metric at the heart of the whole engine

Cheeky and technical at once — drift is literally what the rebalancer hunts. Downside: "drifting" reads as aimless, the opposite of the product's discipline.

principles

Dashboard is home; every screen is one keystroke away and one esc back. No menus, no tabs-of-tabs.

The decision cycle is watchable as it happens — the pipeline is the product's honesty, so it gets a screen, not a log file.

The kill switch is deliberately the ugliest, loudest thing in the app. Safety should not be tasteful.

information design

One row answers five questions per holding: how much, how far from plan (the ◆┼ gauge shows drift spatially), where it's been (7-day sparkline), what it's costing, and whether the data is fresh.

Freshness dots breathe (2.4 s pulse) while data is live; a stale source stops pulsing and goes hollow ○ — you notice the absence of motion.

what animates

Equity sparkline carries a slow cyan shimmer — ambient "alive", never distracting. On a fill, the row flashes green once (380 ms ×2) and the NAV counts up.

color discipline

Amber = the wolf (brand, targets, keys). Green/red = money only. Cyan = data/history. Nothing else gets color, so everything colored means something.

why this screen exists

Transparency as theater. The pipeline tracker makes the architecture visible: stages complete left to right, and the model is provably just one box — with deterministic walls on both sides.

what animates

The active stage runs a braille spinner (80 ms/frame); completed stages snap to ✓. The thesis streams in with a typewriter reveal (18 ms/char) — the one place text "arrives", because it's the one place text is generated.

The running cost line is deliberate: AI synthesis shows its price in real time. Deterministic cycles read $0.00 and skip the THESIS stage entirely.

the money screen for trust

Thesis on top, wall below, receipt at the bottom — the page reads in the exact order the system works. Nothing is summarized away: all 20 rules, every time.

what animates

The rule grid fills at a 28 ms stagger — twenty ticks land in just over half a second, fast enough to feel mechanical, slow enough to register as individual checks. A veto plays the same cascade but stops dead on the red ✗, which stays pulsing. The fill line flashes green twice, then settles.

v0.2 ready

In approval mode this exact screen gains two keys: a approve · r reject. Nothing else changes — trust the user already built here transfers to real decisions.

evaluation as a feature

Every decision row carries its later outcome: did the thesis hold, is an invalidation condition approaching, was it wrong? The system grades itself in public.

Vetoes and no-actions sit in the same list as fills, same visual weight — "we didn't trade" is a result, not an absence.

what animates

Rows cascade in on open. r replays a day: the dashboard re-runs the recorded events at 20× with a REPLAY watermark — the audit log as a VCR.

anti-design, on purpose

No sparklines, no shimmer, no charm. Red frame pulsing at 1.2 s, everything else stripped. The screen should feel like a tripped breaker.

Disengaging is deliberately annoying: press-and-hold or a typed command — never a single accidental key. Both paths are logged with who and when.

reachability

k from any screen. If the runtime trips it automatically (stale-data storm, provider failure loop, rule breach), the reason is the headline.

MOTION LANGUAGE

One vocabulary, used everywhere. Motion always means something — alive, working, arriving, confirmed, or dead. Decorative-only animation is banned; everything below maps to a system state and respects prefers-reduced-motion (Textual: honor a wolf --calm flag).
